
# SEBY AI STUDIO

Plateforme créative avec une interface moderne
et responsive.

## Installation

Installer Node.js 18 ou supérieur.

Dans le dossier du projet :

npm install

Copier .env.example vers .env

Lancer le serveur :

npm start

Ouvrir :

http://localhost:3000

## Fonctionnalités

- Générateur d'images en mode démonstration
- Créateur de logos en mode démonstration
- Assistant rédaction en mode démonstration
- Studio vidéo annoncé comme bientôt disponible
- Navigation responsive
- Historique local des projets préparés

## Important

La génération réelle par intelligence artificielle
nécessite une API IA configurée côté serveur.

La version actuelle ne génère pas réellement
d'images ou de vidéos.
